# Valmeris — fictional Riskr example

Valmeris is a fictional transformation portfolio used to demonstrate Riskr. It contains three programs and 47 risks. The English version comes from the video example; the French version is its source. Both share the same structure and timestamp.

Each language has four `riskr-data.js` files: one portfolio and three standalone programs. The repository's root `riskr-data.js` is the English portfolio. To open another analysis, copy its `riskr-data.js` next to the root `riskr.html`, or place a copy of `riskr.html` beside that data file. Keep private analyses in `riskr-data.local.js`, which Git ignores.

The document links use the reserved `.example` domain. They illustrate the link fields and do not point to a real intranet.
